## 一、风格统一要求

| 项目 | 要求 |
|------|------|
| **整体风格** | 海岛暖调、海洋系手绘插画为主，真实照片为辅 |
| **色调** | 橙红黄暖色调（四期配色各有特色，详见下方） |
| **图标风格** | 圆润可爱、手绘感、海洋元素点缀 |
| **背景图** | Unsplash 真实照片做底图 + CSS 叠加效果 |
| **文件格式** | PNG（透明背景图标）/ JPG（背景图）/ WebP（推荐压缩） |
| **尺寸建议** | 图标 256x256 - 512x512，背景 1920x1080 |

## 三、海边健身房（Gym）🔥

> **核心需求：动作指导图** — 用户需要知道每个动作的正确姿势是什么

### 3.1 背景图（可选）

| 阶段 | 建议氛围 | 推荐关键词（Unsplash） | 状态 |
|------|----------|----------------------|------|
| 月经期 | 细雨凉亭下瑜伽垫 | `yoga mat indoor cozy rain` | ⚡ 可选 |
| 卵泡期 | 晨曦沙滩+健身器材 | `morning beach fitness equipment` | ⚡ 可选 |
| 排卵期 | 正午烈日海边冲浪 | `surfing beach sunny noon` | ⚡ 可选 |
| 黄体期 | 黄昏薄雾划艇 | `kayak misty sunset water` | ⚡ 可选 |

### 3.2 运动指导图 🔥🔥 急需

**这是最重要的资源！** 每个动作需要一张「教学示范图」，清晰展示正确姿势。

建议风格：手绘插画风格（有步骤标注更好），或真人照片（正面/侧面/背面多角度）

| 阶段 | 动作 | 需要展示的内容 | 状态 |
|------|------|---------------|------|
| 月经期 | 冥想 | 盘腿坐姿/散盘坐姿，手放膝盖，背部挺直 | 🔥🔥 急需 |
| 卵泡期 | 罗马尼亚硬拉 | 双手持哑铃，屈髋俯身，背部平直，膝盖微弯 | 🔥🔥 急需 |
| 卵泡期 | 弹力带侧步走 | 弹力带套在膝盖上方，侧向迈步姿势 | 🔥🔥 急需 |
| 卵泡期 | 哑铃侧平举 | 双手持哑铃，手臂从身体两侧平举至肩高 | 🔥🔥 急需 |
| 排卵期 | 冲浪 | 站在冲浪板上，双手张开保持平衡的姿势 | 🔥🔥 急需 |
| 排卵期 | 游泳 | 自由泳/蛙泳的标准姿势，划水动作分解 | 🔥🔥 急需 |
| 黄体期 | 划艇 | 坐在划艇上，双手握桨，划水动作分解 | 🔥🔥 急需 |
| 黄体期 | 慢跑 | 标准慢跑姿势，上半身微微前倾，手臂摆动 | 🔥🔥 急需 |

### 3.3 动作分解图（推荐）🔥 可选

每个动作如果能有 **2-3 张分解图** 会更好，帮助用户理解完整动作流程：

| 动作 | 分解建议 |
|------|----------|
| 罗马尼亚硬拉 | ① 起始姿势 ② 俯身向下 ③ 回到起始 |
| 弹力带侧步走 | ① 弹力带套好 ② 向左迈步 ③ 向右迈步 |
| 哑铃侧平举 | ① 起始 ② 手臂抬起到肩高 ③ 缓缓放下 |
| 游泳 | ① 入水 ② 划水 ③ 换气 ④ 腿部踢水 |
| 划艇 | ① 桨入水 ② 向后划动 ③ 提桨出水 |

### 3.4 健身器材特写图（可选）

如果动作指导图中没有展示器材，需要单独的图片。

| 器材 | 建议风格 | 状态 |
|------|----------|------|
| 瑜伽垫 | 俯视瑜伽垫图，带网格线 | ⚡ 可选 |
| 哑铃 | 马卡龙色系哑铃 | ⚡ 可选 |
| 弹力带 | 不同颜色弹力带展开图 | ⚡ 可选 |
| 冲浪板 | 冲浪板单独展示 | ⚡ 可选 |

### 3.5 动作指导图风格参考

推荐「手绘插画风格」，像健身 App（如 Keep）的教学图：

```
┌─────────────────────────────────┐
│                                 │
│      ┌─────────────────┐       │
│      │   真人/插画     │       │
│      │   动作示意      │       │
│      │                 │       │
│      └─────────────────┘       │
│                                 │
│   📝 动作要点文字说明            │
│   1. 双脚与肩同宽              │
│   2. 背部保持平直              │
│   3. 膝盖不要超过脚尖          │
│                                 │
└─────────────────────────────────┘
```

或者简洁的「剪影风格」：
- 白色人形动作剪影
- 透明背景
- 关键关节处标注动作方向

## 七、获取图片的建议渠道

1. **Unsplash** (unsplash.com) - 免费高质量真实照片
