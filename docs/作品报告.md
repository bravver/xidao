# 汐岛 — 生理周期管理与身心健康助手

---

## 一、作品简介

**汐岛**是一款以"岛屿与潮汐"为隐喻的生理周期管理 Web 应用。它将女性的月经周期重新定义为一种自然节律——如同海洋的潮起潮落——而非需要"处理"的麻烦。应用覆盖周期追踪、日历日志、情绪记录、运动指导、饮食推荐、深度书写和 AI 智慧对话七大模块，所有功能根据用户所处的周期阶段（月经期/卵泡期/排卵期/黄体期）自动适配颜色、内容与建议。

**核心使用场景**：18-35 岁女性在日常生活中记录生理周期、管理情绪波动、获取阶段适配的运动与饮食指导、以及通过 AI 对话获得个性化分析与陪伴。

**核心创新点**：

1. **去医疗化的女性主义设计语言**：以岛屿、海洋、灯塔、贝壳、漂流瓶等意象重构生理周期叙事，文案风格温柔、尊重、非说教，使用"月经""经期"等直接用语而非委婉语
2. **四阶段全感知系统**：颜色主题、背景画面、运动方案、食谱推荐、AI 建议、环境白噪音、甚至日记信纸全部随周期阶段切换
3. **纯前端 + file:// 可运行**：无需服务器、无需安装、无需注册账号，一个 HTML 文件即可在任意浏览器中打开使用全部核心功能
4. **灯塔 AI 角色设定**：AI 被设定为"女性主义视角的温柔引导者"，能基于用户真实的周期数据、情绪记录、运动饮食日志生成个性化回应，而非泛泛的通用回复
5. **多模态交互**：呼吸练习的实时动画引导、烹饪的按压/点击手势、深潜书写的长按潜水机制、信封开启的多段 CSS 动画

## 二、部署链接

本作品采用纯前端架构，支持两种使用方式：

- **离线使用（推荐）**：下载 zip 压缩包，解压后双击 `index.html` 即可在浏览器中打开。所有核心功能无需联网。
- **在线体验（含 AI 对话）**：由于 AI 对话需要向 DeepSeek API 发起 HTTPS 请求，受浏览器 CORS 安全策略限制，需通过本地 HTTP 服务器运行。在项目目录下执行以下任一命令后在浏览器访问 `http://localhost:8080`：

  ```bash
  npx serve dist          # 需要 Node.js
  python -m http.server -d dist 8080   # 需要 Python 3
  ```

### 2. 作品信息

- **作品名称**：汐岛（Xidao / Tide Island）
- **作品类型**：Web 应用（纯前端 SPA）
- **技术栈**：React 18 + Vite 4 · Tailwind CSS · Framer Motion · DeepSeek API · Web Audio API
- **核心理念**：女性的身体是一座岛屿，月经周期是环绕它的潮汐——不是需要征服的敌人，而是值得聆听的节律。

**解决的问题**：

现有经期管理类应用普遍存在三个问题：一是将月经视为"麻烦"或"病症"，语言风格充满医疗化暗示；二是功能单一，仅做日期记录，忽视了周期对情绪、体能、饮食的系统性影响；三是需要注册账号，用户数据存在隐私风险。汐岛针对这三个问题，分别以**女性主义叙事、阶段感知的全功能整合、localStorage 本地存储**做出回应。

### 3. 需求分析

#### 目标人群

18-35 岁女性，特别是：

- 希望更好地了解自己生理周期的年轻女性
- 经期前后有明显情绪或身体变化、希望获得针对性建议的女性
- 关注女性健康、认同女性主义价值观的用户
- 对隐私敏感、不愿在第三方平台注册账号的女性

#### 需求痛点

| 痛点 | 描述 | 汐岛的解决方式 |
|------|------|---------------|
| 医疗化叙事 | 大多数经期 App 使用"症状""治疗""调理"等词汇，暗示月经是病态 | 以潮汐为隐喻，将周期重塑为自然节律 |
| 功能割裂 | 周期记录、情绪管理、运动饮食分散在不同 App 中 | 一个 App 整合七大模块，数据互通 |
| 缺乏阶段感知 | 通用建议不考虑周期阶段差异（如经期第一天建议高强度间歇训练） | 全部功能根据四阶段自动适配 |
| 隐私焦虑 | 生理数据被上传至云端，存在泄露风险 | 全部数据存储在浏览器 localStorage，不收集任何个人信息 |
| AI 缺乏上下文 | 通用 AI 对话不了解用户的具体身体状态 | AI 自动读取用户真实的周期、情绪、日志数据，提供个性化回应 |
| 使用门槛 | 需要下载安装 App | 一个 HTML 文件，双击即用 |

#### 使用场景

- **晨间**：打开汐岛查看今日周期状态，阅读每日格言，获取今日运动与饮食推荐
- **情绪波动时**：在情绪沙滩记录感受，或打开灯塔 AI 的情绪陪伴模式，获取温暖的个性化回应
- **经期前**：AI 自动推荐舒缓运动、镁含量丰富的食物、适合的学习/工作计划
- **深度独处**：进入浮潜区，长按潜水，将心事封存进漂流瓶
- **回顾反思**：在日历模块查看历史日志和情绪记录，用 AI 分析模式与规律

### 4. 功能介绍

#### 4.1 登岛引导（Entry）

新用户首次使用时，输入最近一次月经开始日期和持续天数，即可"登岛"。此信息仅存储在浏览器本地。

> *[截图位置：Entry 页面，展示日期选择器和周期天数按钮组，背景为海洋渐变与浮动光点]*

#### 4.2 岛屿主页（Island）

主控制台，展示：
- **阶段指示器**：当前所处周期阶段图标与名称（如 🌧 月经期 · 第3天）
- **每日格言**：随机展示弗吉尼亚·伍尔夫、西蒙娜·德·波伏娃、张桂梅、上野千鹤子等女性作家/思想家的语录（共31条）
- **四大模块入口**：航海日志、海边健身房、海边厨房、情绪沙滩（2×2 网格卡片）
- **灯塔 AI 入口**：独立金色横幅卡片，点击进入 AI 对话
- **浮潜入口**：底部入口，进入深潜书写区
- **分享卡片**：一键生成包含当日周期信息、格言、运动饮食记录的 PNG 图片
- **环境音开关**：根据周期阶段自动播放对应的环境白噪音（月经期=雨声/卵泡期=微风+风铃/排卵期=海浪/黄体期=篝火），使用 Web Audio API 程序化合成，无需音频文件

> *[截图位置：岛屿主页全景，包含四张模块卡片、灯塔卡片、浮潜入口、阶段指示器、每日格言]*

#### 4.3 航海日志（Ship）

日历月视图 + 日志/计划管理：
- **阶段着色日历**：每个日期单元格自动根据该日在周期中的阶段着色（灰=经期/黄=卵泡期/蓝=排卵期/橙=黄体期）
- **日志（Logs）**：选择日期后在四款阶段主题信纸（雨中信纸、晨曦信纸、蔚蓝信纸、落日信纸）上撰写文字，支持插入图片（自动压缩至宽度 600px）
- **计划（Plans）**：撰写计划后，系统通过关键词规则自动推荐最合适的执行阶段
- **信封动画**：日志以信封图标展示，点击后触发信封开启动画（信封盖翻折 → 信纸滑出 → 蒙层渐显）
- **情绪标记**：日历格上显示当日的情绪记录与日志小圆点
- **AI 分析入口**：一键跳转灯塔 AI"日志分析"模式

> *[截图位置：日历月视图（阶段着色）+ 信封展开动画序列]*

#### 4.4 情绪沙滩（Beach）

每日情绪记录：
- **8 种情绪标签**：愉悦、平静、兴奋、焦虑、低落、烦躁、疲惫、敏感，多选
- **阶段隐喻容器**：月经期=深色鹅卵石、卵泡期=贝壳、排卵期=发光珍珠、黄体期=海星
- **心情笔记**：可附加文字说明
- **历史回顾**：最近 10 条记录，支持查看详情、编辑、删除
- **AI 陪伴入口**：一键跳转灯塔 AI"情绪陪伴"模式

> *[截图位置：情绪选择界面（8个情绪标签 + 容器动画），旁边展示历史记录列表]*

#### 4.5 海边健身房（Gym）

阶段感知运动指导：
- **月经期**：冥想（点击节奏）、轻量拉伸
- **卵泡期**：罗马尼亚硬拉（拖拽交互）、哑铃侧平举（弧线拖拽）
- **排卵期**：冲浪（左右交替）、游泳（左右交替）
- **黄体期**：划船（左右交替）、慢跑（点击节奏）

每种运动均配备：
- **动作分解帧动画**（2-4 帧循环播放）
- **教学参考图**
- **专业指导卡**（技术要领、呼吸节奏、注意力焦点、阶段针对性提示）

**冥想模式**包含专用的呼吸引导 UI：
- 实时呼吸动画（4 秒吸气放大 / 4 秒呼气缩小）
- 呼吸引导文字（"用鼻子缓缓吸气"/"用嘴巴轻轻呼气"）
- 进度环与圆点指示器
- 阶段定制的冥想引导词（月经期=腹部温暖想象/排卵期=巅峰状态能量）

运动完成后获得食材奖励，奖励历史展示（最近 5 条）。

> *[截图位置：健身房主页面 + 冥想呼吸动画 + 任一运动交互画面]*

#### 4.6 海边厨房（Kitchen）

阶段适配烹饪：
- **月经期**：研磨可可豆（长按）+ 烤红薯（点击）
- **卵泡期**：快刀切青柠（点击）+ 捣薄荷叶（长按）
- **排卵期**：煎海鲜大餐（长按）
- **黄体期**：蜂蜜吐司（长按涂抹）+ 煮姜汁红糖水（点击）

每个烹饪步骤展示：食材图标、厨具图片、手势引导图、烹饪说明。圆环进度条实时反馈操作进度。完成后展示成品美食卡片。

> *[截图位置：厨房主页面 + 任一烹饪步骤操作画面 + 成品展示]*

#### 4.7 浮潜区（Snorkeling）

深潜书写机制：
- **长按屏幕潜水**：按压超过 280ms 开始下沉，深度从 0 升至 100
- **短按书写**：在任意深度点击，打开深海主题书写面板
- **漂流瓶系统**：写下的心事被封装成漂流瓶，沉在海底（深度 > 60% 时可见）
- **海盐互动**：他人（或自己）可以在瓶子上留下"海盐"作为默默的认同与陪伴，含盐的瓶子显示发光星点瓶身和海盐计数徽章
- **深度指示器**：右上角实时显示当前深度

> *[截图位置：浮潜深海背景 + 漂流瓶 + 深度指示器 + 书写面板]*

#### 4.8 智慧灯塔（Lighthouse AI）

四种 AI 对话模式：

| 模式 | 功能 | 示例快捷语 |
|------|------|-----------|
| 情绪陪伴 | 倾听情绪，用海洋隐喻回应，不说"你应该" | "我今天心情不太好" |
| 今日推荐 | 基于周期阶段和历史数据推荐 3-5 件事 | "今天适合做什么？" |
| 日志分析 | 分析近期日历日志和情绪记录，发现规律 | "帮我分析最近的情绪" |
| 运动饮食 | 基于周期生理学给出运动饮食建议 | "经期能运动吗？" |

AI 角色设定（"汐汐"）关键特征：
- 温柔的女性主义视角，使用海洋与岛屿的隐喻语言
- 自动读取用户真实数据（周期阶段、情绪记录、日历日志、运动饮食记录），给出个性化回应
- 经期建议基于运动科学和营养学证据
- 避免"你应该"句式，用"可以试试""有些姐妹发现"等建议性表达
- 自伤/自杀提及时有明确的安全边界和危机干预引导

> *[截图位置：灯塔对话界面（显示四模式标签、气泡对话、快捷语按钮），不同模式各一张]*
