# 汐岛 · 项目答辩总结

> 基于生理周期节律的女性自我关怀 Web 应用

---

## 一、项目背景与创意起源

### 1.1 问题发现

在日常生活观察中，我发现女性生理周期对情绪、精力、工作效率有着显著但常被忽视的影响。主流健康应用多以"备孕"或"避孕"为核心场景，鲜有从**自我关怀**与**日常节律管理**角度出发的产品。这促使我思考：能否构建一个不以"生育"为锚点的周期管理工具，而是将重点放在**帮助女性理解自己的身体信号、顺应生理节律安排生活**？

### 1.2 核心创意

我选择用**叙事化岛屿隐喻**来承载整个体验。将四个生理时期映射为四种海洋场景 —— 船入港湾（经期）、扬帆起航（卵泡期）、破浪前行（排卵期）、迷雾巡航（黄体期）—— 每一时期不仅在视觉上变化，更在**推荐内容、交互方式和环境氛围**上形成完整闭环。用户不是在"记录数据"，而是在"经营一座随着身体节律变化的岛屿"。

### 1.3 设计原则

| 原则 | 内涵 | 体现 |
|------|------|------|
| **去污名化** | 直接使用"月经""经期"等词汇，拒绝委婉语 | AI 对话系统明确要求不用"那个""大姨妈" |
| **身体本位** | 用户行为应由身体状态引导，而非日历倒推 | 四期自动切换全部 UI、推荐、环境音 |
| **隐私优先** | 生理数据不应离开用户设备 | 纯前端架构，localStorage 本地存储 |
| **离线可用** | 不依赖网络和服务器 | IIFE 构建，双击 index.html 即用 |

## 二、Vibe Coding 开发过程

### 2.1 什么是 Vibe Coding

Vibe Coding 是一种以**自然语言为驱动的迭代式开发范式**。开发者通过与 AI 编程助手进行多轮对话，以问题描述、功能指令、效果反馈的方式推进开发，而非逐行手写代码。其核心特征是：

- **意图驱动**：用自然语言描述"想要什么效果"，而非"怎么写代码"
- **快速迭代**：AI 生成第一版 → 观察效果 → 反馈修正 → 持续优化
- **设计先行**：先确定视觉风格与交互体验，再倒推技术实现
- **人机协作**：开发者负责创意方向、设计决策和质量把关，AI 负责代码生成与调试

### 2.2 本项目的 Vibe Coding 实践

#### 第一阶段：概念具象化（第 1-3 轮对话）

从模糊的"想做一款周期管理工具"出发，通过与我（Claude）的对话逐步明确：

1. **确定隐喻体系**：岛屿 + 海洋 + 四个时期 → 四个场景（海船·健身房·厨房·海滩）
2. **确定功能模块**：日志、运动、饮食、情绪、漂流瓶社区、AI 灯塔
3. **确定技术路线**：React + Vite 纯前端，localStorage 持久化，file:// 协议分发

#### 第二阶段：骨架搭建（第 4-8 轮对话）

通过自然语言指令建立项目基础设施：

- "创建一个 Vite + React 项目，配置 Tailwind CSS"
- "设计 CycleContext 管理生理周期状态，自动计算当前时期"
- "搭建 Island 主页，六个模块卡片导航"
- "实现 Entry 页面，用户输入经期日期注册"

每轮对话后即时观察效果，发现问题立即反馈修正。例如初始设置时发现 `index.html` 无法直接双击打开 —— 定位到 Vite 源码入口与构建输出的区别，通过配置 `base: './'`、`format: 'iife'` 和自动清理插件解决。

#### 第三阶段：模块深化（第 9-20+ 轮对话）

六个功能模块逐一深化，每个模块经历多轮迭代：

- **海船模块**：日历系统 → 日志/计划双轨 → 关键词智能分类 → 信封 3D 动画 → 滚动堆叠修复
- **健身房模块**：分时期运动推荐 → 定时/计数/帧动画三种模式 → 自定义运动计划
- **厨房模块**：交互式烹饪流程 → 拖拽/研磨/切剁/翻面/冲泡五种交互 → 自定义食谱系统
- **情绪海滩**：8 种情绪标签 → 分时期封存物 → 历史记录滚动优化 → AI 情绪陪伴
- **浮潜模块**：漂流瓶社区 → 三层深度递进 → 匿名投瓶/捞瓶
- **智慧灯塔**：DeepSeek API 接入 → 四模式切换 → Persona 系统 → 安全边界

#### 第四阶段：打磨与分发（第 20+ 轮对话）

- 修复多个模块的列表堆叠问题（flex-shrink 导致的压缩）
- 信封弹窗长内容滚动重构
- 黄体期背景音从篝火换为秋日柔风
- 生成项目架构图和技术文档
- 压缩 dist 目录为分享包（37MB ZIP）

### 2.3 Vibe Coding 心得

本项目总计约 **30 轮对话迭代**，从概念到完整交付。我的角色始终是**产品经理 + 设计师 + 质量把控者**，而非代码打字员：

- **创意决策**在我：选择隐喻体系、定义功能范围、确定视觉方向、判断体验优劣
- **代码执行**在 AI：根据我的描述生成实现、修复 bug、优化性能、处理兼容性
- **反馈闭环**：我观察效果 → 用自然语言描述"哪里不对"和"期望什么"→ AI 修正 → 我再观察

这种范式的核心价值在于**将开发速度从"打字速度"解放为"思考速度"**。

## 四、核心技术实现

### 4.1 周期计算引擎 (`utils/cycleCalculator.js`)

以用户注册的经期首日 `lastPeriod` 为锚点，基于标准 28 天周期模型，计算任意日期的生理阶段：

```javascript
核心算法：
  daysSinceLastPeriod = floor((today - lastPeriod) / 86400000)
  cycleDay = (daysSinceLastPeriod % 28) + 1

  cycleDay ∈ [1, 5]     → period     (月经期)
  cycleDay ∈ [6, 13]    → follicular (卵泡期)
  cycleDay ∈ [14, 16]   → ovulation  (排卵日)
  cycleDay ∈ [17, 28]   → luteal     (黄体期)
```

`getPhaseForDate()` 函数支持任意过去/未来日期的相位查询 —— 这是海船日历模块能够跨月份导航的技术基础。

### 4.2 全局状态管理 (`context/CycleContext.js`)

采用 React Context + useMemo 模式：

- **Provider 层**：从 localStorage 读取 `lastPeriod`，通过 `useMemo` 实时计算 `cycleDay`、`phase.name`、`phase.label`、`daysUntilPeriod`
- **Consumer 层**：任意子组件通过 `useCycle()` 三行代码接入周期状态，无需 props 传递
- **持久化**：状态变更自动同步 localStorage，页面刷新不丢失

### 4.3 程序化环境音引擎 (`hooks/useAmbientSound.js`)

567 行纯 Web Audio API 实现，四个独立的声音合成器：

```
声音生成流水线：
  噪声源 (白/粉/布朗) → BiquadFilter (低通/带通/高通)
  → LFO 调制 (OscillatorNode 控制 Gain 或 Frequency)
  → GainNode (音量控制) → AudioContext.destination

四期音景：
  经期   → 雨声：白噪声带通(800Hz) + 粉红细雨层 + 水滴正弦铃铛
  卵泡期 → 晨风+风铃：布朗噪声低通(400Hz) + 随机泛音(C5-E6)
  排卵期 → 海浪：粉红噪声潮汐LFO(0.07Hz) + 泡沫层 + 深层低频
  黄体期 → 秋日柔风：布朗噪声双层LFO + 树叶沙沙 + 低频暖意
```

**技术亮点**：
- 使用 IIR 近似算法生成粉红/布朗噪声，避免离线音频文件
- LFO 调制模拟自然声的不规则起伏（潮汐周期、风力变化）
- `setTimeout` 递归调度随机事件（水滴、风铃、树叶翻转），避免固定间隔的机械感
- 组件卸载时自动清理所有 AudioNode，防止内存泄漏

### 4.4 厨房交互式烹饪系统 (`pages/Kitchen.jsx`)

1,406 行代码实现五种独立交互模式，全部基于浏览器原生事件：

| 交互 | 事件监听 | 进度计算 | 视觉反馈 |
|------|----------|----------|----------|
| 拖拽投料 | mousedown/move/up + getBoundingClientRect | 落区碰撞检测 | 食材跟随光标 + 弹簧回弹 |
| 长按研磨 | setInterval(50ms) 推进进度 | 进度百分比 → 食材阶段映射 | SVG 圆环 + CSS filter 渐变 |
| 快速切剁 | mousemove velocity 计算 | 切片计数 → 进度百分比 | 切片轨迹粒子 + 裂开动画 |
| 滑动翻面 | mousemove 横向位移计数 | flipCount 达到阈值触发 | CSS rotateY 翻转 |
| 点击推进 | onClick + tapProgressStep | 逐步累加到 100% | 进度条填充 + 成品图渐变 |

**自定义食谱系统**：用户可通过表单创建自定义食谱（名称、emoji图标、适配时期、烹饪方式、步骤描述），存储在 `localStorage`，在烹饪时与内置食谱并列选择。

### 4.5 海船日志系统 (`pages/Ship.jsx`)

1,085 行代码实现完整日历 + 日志系统：

- **日历渲染**：动态计算每月天数 + 首日偏移，CSS Grid 7列布局
- **时期着色**：每个日期根据 `getPhaseForDate()` 计算结果渲染对应时期的背景色
- **日志/计划双轨**：同一日期支持日志（过去记录）和计划（未来安排）两种类型
- **智能推荐**：根据计划内容的关键词匹配最合适的生理时期，给出建议标签
- **信封动画**：纯 CSS 实现 3D 信封展开 —— 封盖 `clipPath: polygon(▲)` + `rotateX(180deg)` + `cubic-bezier` 缓动，信纸层延迟滑出形成层次感

### 4.6 健身房运动引擎 (`pages/Gym.jsx`)

1,367 行代码实现五种运动模式：

- **计时运动**：`setInterval(1s)` + SVG stroke-dashoffset 圆环进度 + 随机鼓励话语
- **触控计数**：touch 事件上下滑动检测，rep 计数 + 进度百分比
- **帧动画**：`setInterval(400ms)` 循环切换分解动作教学帧图
- **冥想呼吸**：`requestAnimationFrame` + LFO 驱动 `breathingPhase` 切换与缩放动画
- **自定义运动**：用户可创建个性化运动计划，与内置运动共享同一执行流程

### 4.7 智慧灯塔 AI 对话 (`utils/aiChat.js` + `pages/Lighthouse.jsx`)

- **API 层**：直接调用 DeepSeek Chat API，fetch + ReadableStream 流式输出
- **Persona 系统**：精心设计的 Prompt —— "灯塔守护者汐汐"，温柔坚定的女性陪伴者，以海洋意象翻译身体经验
- **四模式切换**：情绪陪伴、今日推荐、日志分析、运动饮食，各有独立的系统指令
- **上下文注入**：自动采集周期数据、最近情绪记录、当日日历日志，一并发送给 AI
- **安全边界**：自伤/自杀场景的温柔引导话术，医疗症状拒绝诊断，不确定时诚实表达

### 4.8 IIFE 离线构建 (`vite.config.js`)

通过三项配置实现 `file://` 协议直接运行：

```javascript
base: './'                              // 资源路径相对化
output: { format: 'iife' }              // 自执行函数，无需模块加载器
build: { inlineDynamicImports: true }   // 动态导入全内联
```

配合自定义 Vite 插件 `removeModuleType()`，在构建时自动清理仅开发环境使用的脚本标签，确保 `dist/index.html` 纯净可用。

## 五、创新亮点总结

### 5.1 叙事化交互设计

将生理周期管理从"数据记录"升华为"岛屿经营"的叙事体验。四个时期的视觉、音频、推荐内容形成完整的世界观闭环，用户在无形中完成了周期数据的积累。

### 5.2 程序化环境音合成

以 567 行 Web Audio API 代码替代音频文件，实现四种完全不重复的自然音景。从白噪声到 IIR 滤波到 LFO 调制到随机事件调度，构建了一套完整的实时音频合成管线。

### 5.3 五种原生交互模式

厨房模块在不引入任何第三方手势库的前提下，基于浏览器原生 Touch/Mouse 事件实现了拖拽、长按、切剁、翻面、点击五种独立的交互模式，每种都有独立的进度计算和视觉反馈逻辑。

### 5.4 隐私优先的离线架构

全部用户数据存储在浏览器 localStorage，不经过任何服务器。通过 IIFE 构建，应用可以像打开 PDF 一样直接双击 `index.html` 运行，完全脱离网络和服务器依赖。

### 5.5 AI 辅助的 Vibe Coding 开发范式

本项目从概念到完整交付，全部通过自然语言与 AI 编程助手对话完成。30 轮迭代，9,638 行代码，8 个页面模块，12 个共享组件 —— 开发者聚焦于创意决策和体验设计，代码执行由 AI 完成，体现了人机协作的新型软件开发模式。
