> 一个仍在生长中的 Web 原型：用岛屿、海洋与四季般的周期变化，承载生理周期记录、情绪觉察和日常自我关怀。

## 关于这个项目

汐岛尝试把传统周期工具里偏功能化、偏医疗化的体验，转换成更柔和的岛屿叙事。用户输入最近一次月经开始日期后，页面会根据周期阶段改变主题、内容与互动建议，并把记录保存在当前浏览器中。

它目前是一个个人创意原型，不是成熟产品。代码、交互和健康内容都还有继续验证与打磨的空间，也不应替代专业医疗意见。

## 已实现的体验

| 场景 | 当前功能 |
| --- | --- |
| 岛屿主页 | 28 天周期估算、四阶段视觉变化、模块导航 |
| 海船日志 | 日历查看、日志与计划记录、阶段回顾 |
| 情绪海滩 | 情绪标签、情绪封存与历史记录 |
| 海岛健身房 | 分阶段运动建议、动作引导、自定义计划 |
| 海边厨房 | 分阶段饮食灵感、交互式烹饪、自定义食谱 |
| 浮潜 | 呼吸练习、冥想互动、漂流瓶体验 |
| 智慧灯塔 | 可选的 DeepSeek 对话能力，用于情绪陪伴和日常建议 |

## 技术栈

- React 18 + Vite 4
- Tailwind CSS
- Framer Motion
- Web Audio API、Canvas API、localStorage
- DeepSeek Chat API（可选）

## 本地运行

需要 Node.js 18 或更高版本。

```bash
git clone https://github.com/bravver/xidao.git
cd xidao
npm install
npm run dev
```

浏览器打开终端中显示的本地地址，通常是 `http://localhost:5173`。

### 可选：启用灯塔 AI

不配置 API Key 时，其余本地功能仍可正常体验。

```bash
cp .env.example .env
```

随后在 `.env` 中填写：

```env
VITE_DEEPSEEK_API_KEY=your_key_here
```

安全提醒：Vite 会把 `VITE_*` 变量写入浏览器端构建产物。请只在本地原型演示中使用受限、可随时撤销的 Key，不要把长期有效的 Key 用于公开部署。更成熟的实现应通过后端代理调用模型 API。

## 构建与检查

```bash
npm run check
npm run preview
```

`npm run check` 会执行生产构建，产物生成在 `dist/`。构建后的核心页面可以离线使用；灯塔 AI 仍需要网络与有效配置。

## 数据与隐私

- 周期、情绪、日志、运动与食谱等数据保存在浏览器 `localStorage` 中。
- 项目目前没有账号系统或后端数据库。
- 清除浏览器站点数据会同时清除本地记录。
- 漂流瓶“社区”当前为本地原型体验，不代表真实在线社区。

## 项目结构

```text
xidao/
├─ src/
│  ├─ components/    # 通用组件与场景背景
│  ├─ context/       # 周期全局状态
│  ├─ data/          # 原型展示数据
│  ├─ hooks/         # 环境音等复用逻辑
│  ├─ pages/         # 各岛屿场景页面
│  ├─ styles/        # 动画样式
│  └─ utils/         # 周期计算与 AI 调用
├─ docs/             # 设计说明、架构与作品文档
├─ index.html
└─ vite.config.js
```
